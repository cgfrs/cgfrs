# Oracle SQL & Dados

Uso Oracle SQL para investigar dados, validar regras de negócio, apoiar implantações e criar soluções operacionais mais seguras e previsíveis.

## Foco atual

- Consultas para diagnóstico e suporte
- Validação de relacionamentos e integridade
- Scripts com foco em segurança e rastreabilidade
- Apoio a dashboards e indicadores
- Análise de estruturas e dependências em bases Sankhya

## Princípios que sigo

- Evitar operações destrutivas sem validação
- Respeitar dependências e integridade referencial
- Trabalhar com rollback e conferência antes de commit
- Documentar premissas, riscos e critérios de validação

> O objetivo não é apenas escrever SQL, mas usar dados para entender o processo e resolver o problema certo.
